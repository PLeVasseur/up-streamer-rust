# Reference Streamer applications

The reference binaries show classic endpoint construction, subscription-provider
selection and route installation. They are bridge applications, while
`example-streamer-uses` contains the publisher/subscriber, notifier/notifyee and
client/server roles on either side.

For explicit owned-frame/native-loan route families and deployment agreements,
use `configurable-streamer` and its native deployment guide. Payload encoding,
wire selection and physical endpoint API are separate configuration decisions.
Native middleware setup remains documented by each binding.
